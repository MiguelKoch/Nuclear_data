# Nuclear data

Nuclear reactor construction starts per year, 1951–2026, split into completed, abandoned and still under construction, with Three Mile Island (1979) and Chernobyl (1986) marked.

Data: [World Nuclear Industry Status Report interactive dataviz](https://dv.worldnuclearreport.org/), as of 16 October 2026. Counts are by each reactor's original construction-start year across all 835 units in the dataset.
